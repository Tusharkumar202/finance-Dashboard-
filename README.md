# 🏦 Banking Financial Performance Dashboard | Power BI

## 📌 Project Overview

An interactive **Banking Financial Performance Dashboard built using Microsoft Power BI** to analyze key banking metrics, including **loans, deposits, clients, assets, income, credit card balances, and customer demographics**.

The dashboard provides dedicated analysis for **Loan Performance, Deposit Performance, and Overall Financial Summary**, with interactive filters for year, gender, banking relationship, and investor advisor. It helps transform banking data into clear and actionable business insights.

## 🔍 Key Features

* 💰 **Loan Analysis** – Analyze total loans, bank loans, loan distribution, income bands, occupations, and nationalities.
* 🏦 **Deposit Analysis** – Track total deposits, savings accounts, checking accounts, and deposit performance.
* 📊 **Financial Summary** – Monitor total clients, loans, deposits, assets, average income, average credit card balance, and loan-to-deposit ratio.
* 👥 **Customer Analysis** – Analyze customers based on gender, nationality, occupation, income band, and banking relationship.
* 📅 **Year-wise Analysis** – Compare financial performance across different years.
* 🎯 **Interactive Filters** – Use Year, Gender, Banking Relationship, and Investor Advisor filters for dynamic analysis.
* 📈 **Interactive Visualizations** – KPI cards, bar charts, and donut charts for effective data storytelling.

## 🛠️ Tools & Skills

**Microsoft Power BI | DAX | Data Analysis | Data Visualization | Business Intelligence | Dashboard Design**

## 🎯 Project Objective

The objective of this project was to build an interactive banking analytics solution that provides a **360° view of financial performance** and helps identify trends in loans, deposits, customer segments, and overall banking operations.

## 💡 Business Insights

The dashboard can help identify:

* Loan and deposit performance
* High-performing customer segments
* Loan distribution across occupations and nationalities
* Customer demographics
* Income-band contribution to loans
* Banking relationship performance
* Changes in financial KPIs over time
* Overall financial health through key performance indicators
